# No-minimap localization module

This package provides the GUI, image/video entry points, scene atlas builder, SIFT/XFeat localization backends, ladder overlay, and optional navigation experiments.

For installation, GUI controls, map data layout, and safety notes, see the repository [README](../README.md).

The default GUI workflow is read-only. The separate full-route trial and input-service controls can send game inputs; use those controls only when you intend to run that experiment.
